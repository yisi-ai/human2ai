# 有目标的精修结果

用户授权在现有“精修”视图中显示决策依据和最终关系达成情况；画布只显示构图内容，不显示数学规则辅助线或其开关。沿用当前简洁视觉方向和 candidate 生命周期，不建立新的批准基线。

复用 CompositionWorkflowView、CompositionCanvas、CanvasScene、TabSwitch 。不增加新通用组件。精修数学、计划、持久化和原稿版本归 composition 领域与页面所有，视图只展示输入结果。

- v1 结果继续使用现有概述；v2 显示目标、观察、不确定性、保留项、取舍和每条关系的前后测量。
- 零操作保留结果有明确完成说明，不显示空规则列表。
- 规则辅助线及开关不渲染；原有动势线、形状、焦点和图片按构图内容正常显示。
- 原稿、精修及生成预览不渲染规则辅助线；图片和提示词导出仍由草稿数据生成。
- 过期、等待和失败结果使用现有不可用视图规则。
- 沿用桌面支持范围，长说明换行并在现有工作区内滚动。

确定性证据：CompositionWorkflowView.stories.tsx 的 DirectedRelations、RetainedComposition 及已有 Ready/Stale/Waiting 等场景。检查关系摘要、构图内容可见及规则辅助线不渲染。

桌面运行检查通过：1024×800 与 1280×800 下，画布可见、长说明可内部滚动且无横向溢出；保留结果无空规则列表，旧结果在原稿变化后失效并预览当前原稿。Storybook 和生产构建、类型检查、i18n、领域基线及 UI doctor 通过。

语义移除：composition.refinement.ruleGuides 原本表示精修数学叠加线的本地显示开关，不是动势线节点。按用户要求删除该控件与中英文文案，不迁移或复用为其他概念；数值关系验证继续保留。
