# 空间与摄像机固定视图

用户明确要求沿用构图和 UI 界面的布局：画布上方固定两个标签“空间 / 摄像机”，摄像机视图每行展示三个摄像机名称和视角。此次沿用现有布局方向，不建立新的视觉基线；本地资产继续保持 candidate。

选用 CompositionWorkflowView 的 stateControls / children 插槽复用居中标签栏与工作区；同步 0.14.0 experimental TabSwitch 负责固定视图切换，已有空间面板持续使用同一资产。LoadingState、Alert 和 BasicButton 复用已有加载、失败和重试呈现。摄像机网格作为 SpatialWorkspaceView 内部页面组合，不新增通用组件。

已查询并排除 UiSketchStateTabs（用户可增删的状态，不适用于固定视图）和 ImageTitleCard（图片渐隐、标题覆盖与单行截断，不适合完整检查镜头构图、加载失败和长名称）。使用简单 figure / figcaption 承载每个镜头，图片完整等比显示。

视图切换仅属于本地状态，不写入空间文档或历史；保留已挂载的空间编辑器以保持轨道视角。摄像机视图只读取当前 draft.cameras 和页面注入的 cameraSource，使用现有按 revision 生成的普通镜头预览，名称和列表跟随当前草稿；待保存时显示占位，失败时支持逐项重试。不新增 API、领域操作或持久化 schema。

文案先记录 spatial 语义：摄像机复用既有集合概念，“空间”为 3D 空间概念的简短标签变体，顶部切换的辅助名称独立于右栏标签；中英文同步。覆盖混合画幅、多行摄像机、长名称、英文、待保存和失败状态。使用 Story play 与桌面浏览器检查三列、内部滚动、键盘切换、返回空间后保留编辑器以及列表变化；运行 i18n、YisiUI doctor、类型检查、Storybook 与 Next 构建。

摄像机卡片通过共享 BasicButton 覆盖名称与预览点击区，复用 choose(cameraId) 选中逻辑，打开 AppShellFrame 右栏并切到对应参数；保持摄像机总览和滚动位置。沿用现有“参数 / Properties”概念与摄像机名称作为辅助操作名称，无新增文案。按钮提供键盘与选中状态，预览失败时重试按钮仍独立可用；只读状态允许查看参数，编辑控件继续遵循既有禁用条件。不采用包含重试按钮的嵌套按钮卡片，不新增领域操作。

总览和参数区隐藏可见滚动条，保留滚轮、键盘和内部滚动；工作区外层不增加第二条滚动轨道。按用户要求复用现有布局，不修改同步资产或其他页面滚动方式。

“显示摄像机 / Show cameras”沿用工具区既有 Checkbox，与显示关节与骨段同属本地视图开关；不是切换摄像机总览或更改光照。默认开启，关闭时隐藏全部摄像机辅助线。SpatialViewport 将原单个 CameraHelper 扩展为同一场景内的辅助组，继续复用 createOutputCamera，显示每台摄像机在目标平面处的取景范围；选中镜头使用既有选中色。开关、选择及辅助线不进入空间文档、PNG、版本历史或预览输入，不触发保存。重新绘制和卸载时释放辅助几何及材质。该变化只扩展现有 UI 呈现，不新增领域操作或通用组件。

逐镜头预览由 Web 适配层记录可复用的已保存 revision：对比 createSpatialScene / renderSpatialPng 的场景输入和当前摄像机设置；人物、物体和光照变化使全部镜头失效，摄像机变化只影响自身，摄像机名称、其他摄像机和观察盒不影响该镜头输出。保存未完成时只撤下已变化镜头的旧图，未变化镜头维持原 URL 和图像实例；保存返回、外部版本、撤销和重做均按实际草稿比较。复用 SpatialEditQueue、DraftVersionStore 和既有按版本的 PNG API，不更改版本存储、服务端缓存或构图引用规则。领域基线归属为 spatial.scene-authoring 的本地 Web 适配，不提取共享缓存能力或修改业务契约。

用户追加要求移除画布上的全部提醒文字。保存中与保存成功不渲染状态文字，移除不再使用的 spatial.saving / spatial.saved 中英文资源及语义。读取、保存或约束错误仅在固定标签“空间”左侧显示错误图标，复用 Tooltip 与 BasicButton：悬停或键盘聚焦显示既有错误原因，有恢复操作时点击图标重试。图标独立于标签，不改变当前视图。摄像机图片自身的加载、失败与重试仍属于各镜头预览。
