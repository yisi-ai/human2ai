# 三类画布的撤销与重做

构图、UI 界面和 3D 空间沿用现有桌面工作区布局，在画布左下角组合项目本地 candidate CanvasHistoryControls。查询并复用同步的 BasicButton、现有撤销/重做图标和主题变量；视口缩放控件只管理观察相机，不承担文档历史，因此新增受控按钮组合。组件只接收可用状态、回调和本地化标签，不持有草稿、会话或 API。共享资产仍保持同步版本的 experimental 状态，不变更既有视觉方向。

命名复用决策：新增 shared canvas-history.undo、canvas-history.redo 和 canvas-history.label 三个语义，统一使用 canvasHistory.undo/redo/label；移除仅用于空间的 spatial.undo。两种清空画布确认保留既有确认交互，移除“无法撤销”的说明，中文与英文同步。

领域比较包括三个页面的草稿修改入口、空间操作队列、DraftVersionStore 与 capture.draft-versioning。提取共享 capture.canvas-edit-history：完整草稿快照记录本次打开会话最近 100 步；单次指针操作、连续按键或一次输入编辑合并为一步，无变化不入栈，撤销后新修改清空重做。UI 界面的历史同时记录修改前后活动状态；切换状态本身不进入历史。选择、编辑观察相机和画布缩放不进入历史。刷新、切换会话或接收外部 revision 后重置本地历史，自动保存确认不重置。

Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做。快捷键限定画布、工具面板及独立挂载的节点编辑器，文本输入保留浏览器原生撤销。恢复时取消未完成的指针变换和临时预览；一次拖动不产生逐帧历史。

构图和 UI 界面仍通过原有串行自动保存写入完整草稿；迟到的保存响应及外部读取不能覆盖新修改。revision 冲突停止继续写入，等待重新加载。3D 空间继续逐个提交经过领域校验的操作，确保每个可撤销目标都有已保存版本；新空间先保存初始草稿。撤销/重做立即更新本地文档，排队后按目标历史 revision 恢复，不受当前保存请求阻塞。共享版本存储新增指定版本恢复，在同一会话内读取已验证的历史草稿并追加新 revision，保持并发检查、风格加工元数据和不可变历史；不通过任意草稿覆盖绕开空间的关节固定或运动边界校验。已有服务端 undo 行为保持兼容。

保留的交互证据为 CanvasHistoryControls 的 Composition、UiSketch 和 Spatial Stories，使用实际画布与公共历史 Hook。覆盖连续拖动只撤销一步、完整恢复与重做、文本输入不抢占快捷键、空间属性修改。单元测试覆盖 100 步上限、分支重做清理、空操作、状态上下文及空间保存过程中撤销；共享版本集成测试覆盖三类领域的指定版本连续恢复、并发冲突、非法输入和不存在版本。

2026-09-14 验证：三个 Stories 在浏览器通过；独立生产服务使用临时 SQLite 验证 UI 删除恢复、跨状态撤销、延迟保存响应时撤销、Agent 外部版本重置和刷新；空间新增人物在保存响应未返回时撤销，随后重做，服务端版本依次保留初始、新增、撤销、重做结果；构图新增和删除可连续撤销与重做。1280×800 UI 和 1024×800 空间桌面窗口检查按钮可见、可操作，无新布局重叠。

服务端、Web、Storybook 类型检查及两项生产构建通过；domain-baseline check/test、i18n check、YisiUI doctor/check 通过。全量测试 633 项通过、1 项跳过，2 项已有断言失败：composition-cli 仍期待 5 个方法而已有 9 个；createI18n 仍期待“加工”而现有标签为“精修”。已核对本次修改前的 HEAD，未改动这些无关断言。
