# UI 界面范围与画布节点

界面范围作为输出边界；区域、文字和图片可以移到范围外，继续参与选择、移动、编辑和既有草稿保存。移出不删除节点、不修改 visible，也不自动扩大界面范围。部分相交的节点继续输出完整位置与尺寸，完全在外或仅贴边的节点不进入静态提示词。动效提示词保留开始或结束状态有可见交集的节点及其两端几何。

复用 UiSketchCanvas、CanvasNode、CanvasScene 与 InfiniteCanvasViewport。这里只移除 UI 适配层的位移约束，通用节点交互与构图领域不变；提示词的交集规则属于现有 local 能力 ui-sketch.layout-intent，静态与动效输出调用同一判断。文字通过调用方传入既有实测边界，缺少相应测量时沿用原有确定性估算。共享草稿版本、API 与稳定 schema 不变。

保留现有桌面视觉方向与 candidate 状态。界面范围、静态提示词、动效提示词继续复用原有中英文语义和标签，只更新内容选择规则。交互证据为 UiSketchCanvas.stories.tsx 的 NodesOutsideFrame；单元测试覆盖三类节点、移动后的界面范围、四侧内外与贴边、部分交集、动效进出、文字实测边界，以及输出不修改原草稿。

2026-09-06 验证：全量 38 个测试文件、423 项测试通过，领域契约 103 项测试通过；类型检查、生产构建、Storybook 构建、语义检查、领域检查、YisiUI doctor/check 和 Agent skill 校验通过。浏览器中的 NodesOutsideFrame 交互通过，在 1280 × 800 与 1024 × 800 桌面视口核对节点仍可在范围外编辑、部分移回后恢复进入提示词。隔离的生产服务验证了范围外节点键盘移动后的自动保存、刷新后位置保持，以及复制提示词排除范围外节点并保留范围内节点和全局备注；控制台无错误或警告。
