# 会话风格联动

## 责任与资产选择

用户已授权实施构图 / UI 会话与风格库联动。保留现有工作台与风格卡片方向，新增入口位于右侧基本信息下方。此授权覆盖功能实现，未将候选组件或整体视觉基线宣称为稳定版本。

已比较 `CompactDropdownSelect`、`SessionDetails`、`StyleLibraryView`、`BasicButton` 与 Ant Design Modal。紧凑下拉适合纯选项，但不足以预览设计规范和参考图；复用 `StyleLibraryView` 的卡片、筛选与预览，并为其增加受控选择动作。新增本地候选 `SessionStylePicker` 组合该视图与既有按钮、模态框，不复制另一份风格库。

应用层 `useSessionStyle` 负责读取、轮询和绑定，组件只持有弹窗开关。两个工作台复用同一绑定和短句读取逻辑，画布文档、自动保存和多阶段处理仍由各自领域持有。风格库编辑分别提供完整设计规范与简短特征句；复制时仅加入短句。

## 状态与交互

风格预览底部的“使用此风格”按钮靠右对齐，复用 `sessionStyle.select` 的绑定动作语义及中英文文案。

Stories 覆盖选择、预览、绑定、解除、已绑定、待加工、加载中、空库、错误、保存禁用和窄侧栏长名称。按钮使用同步组件的键盘契约，模态框继承焦点约束和 Escape 关闭；保存期间阻止关闭，解除不会删除风格或画布。构图节点编辑器复用 UI 节点的来源与只读说明语义，Agent 新增节点仍可编辑与删除。

- 全套 Vitest 通过 34 个文件 / 384 个测试；领域基线矩阵通过 12 个文件 / 84 个测试，服务端、Web、Storybook 类型检查及 i18n、YisiUI doctor 均通过。技能目录校验通过。

## 3D 空间与消费项目建模

3D 空间复用现有 `SessionStylePicker`、`StyleLibraryView`、`useSessionStyle` 和共享会话绑定，在基本信息之后展示风格入口，默认筛选 `spatial`。继续使用已同步的实验态 TabSwitch、BasicButton 及既有候选组件，不改变工作台视觉方向。CompactDropdownSelect 仍不适合同时预览参考图与完整规范；通过 SpatialWorkspaceView 的既有 details 插槽组合，无需新增面板组件。

风格说明指导消费项目的形体、材质、配色和光照，空间指导布局、尺度、姿态及相机。绑定不修改空间草稿。消费项目建模完成度不属于本地画布加工状态，空间入口因此不展示“尚未按当前风格加工”。分类、绑定、解除、加载、错误、禁用和长名称沿用现有交互；新增 3D 选择 Story，桌面验证沿用 1024×800、1280×800 与 1536×960 中的相关视口。

本次验证：共享领域矩阵 22 个文件（180 通过、1 项既有跳过）；分类 CLI、风格 API、旧库升级及消费接入相关测试通过。服务端、Web、Storybook 类型检查，i18n、领域基线、YisiUI doctor、Skill 校验与分发边界检查通过；Next 生产构建和 Storybook 构建通过（Storybook 保留既有包体积提示）。隔离服务实测创建 3D 风格、空间默认筛选、预览和绑定、CLI 读取同一规范、英文解除绑定；绑定没有创建空间草稿版本。1280 与 1024 桌面宽度无页面横向溢出，风格控件及中英文选择弹窗的局部 axe 检查无违规，3D 选择 Story 的绑定/解除交互完成且无 play 错误。
