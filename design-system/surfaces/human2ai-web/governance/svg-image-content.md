# 图片节点的 SVG 内容

沿用图片节点编辑器及现有桌面视觉方向，在图片内容面板增加 SVG 粘贴与直接复制源码入口。继续使用现有 CanvasImage、CanvasImageEditorFields、BasicButton 与实验态 ActionButton；CopyAction 已弃用，TextMarkEditor 的富文本标记职责不适合承载原始源码。没有新增组件或改变现有资产的 candidate 状态。

图片上传与源码读取由应用层回调提供；该面板不读取会话或直接访问 API。源文件仍由会话持有，PNG/JPEG/WebP/SVG 共用图片引用、显示与替换流程。复制按钮直接将原文写入剪贴板，不展开源码；粘贴输入使用文本框，不把源码作为 HTML 注入页面。Agent 默认生成透明背景，仅保留所需图形、填充和描边；画布底色不进入源文件，上传内容保留原样。

粘贴入口聚焦文本框，空输入和保存期间禁用提交；失败保留输入，取消仅关闭输入。源码复制在只读节点中仍可用。读取失败提供重试，切换图片时丢弃过期读取结果。长源码输入在面板内滚动，复制始终保留完整原文。

交互证据位于 CanvasImageEditorFields.stories.tsx：SvgSource、PasteSvg、SvgReadFailure、SvgReadOnly、LongSvgSource。生产页面沿用 1024×800、1280×800、1536×960 的桌面范围。自动检查和浏览器验证不代表用户批准了新的视觉基线。

2026-09-06 验证：生产构建中检查了 UI 画布粘贴、1024×800 与 1280×800 图片面板，以及 1536×960 构图会话的 Agent 上传、重新加载和预览。两类会话复制的 PNG 均保留 SVG 图形；CLI 导出的源码与输入文件完全一致。全量 408 项测试、领域契约 103 项测试通过。SVG 图片校验复用 asset.image-validation，显式启用会话 SVG，风格参考图继续保持位图契约。

按用户最终要求改为直接复制后，浏览器再次验证普通、只读、长源码的完整复制及粘贴流程，生产页面复制结果与服务原文一致且未出现源码查看区。直接渲染 SVG 资源时，图形外像素 alpha 为 0，图形内 alpha 为 255。更新后的类型检查、生产和 Storybook 构建、i18n 与 YisiUI 检查通过；中英文沿用复制语义并移除查看语义。

## 图片原文件下载

构图与 UI 界面继续共用 CanvasImageEditorFields，在图片内容操作行增加下载入口。应用层注入 readImageFile，通过既有会话图片内容接口读取完整 File；SVG 源码复制与下载共用读取结果，下载保持原始字节和 PNG/JPEG/WebP/SVG 格式。服务端、图片校验、草稿 schema 和领域基线契约均不变。

复用现有实验态 BasicButton 的键盘、禁用和 loading 行为。保存对话框取消应安静返回，因此该动作不采用 ActionButton 的成功反馈。图片读取完成后才允许下载，从点击同步打开系统保存对话框；不支持该 API 时使用浏览器 Blob 下载。空节点不显示入口，只读节点仍能下载，上传及下载期间防止重复提交；失败显示本地化错误并允许重试。切换图片丢弃过期读取，下载使用源文件而非画布裁剪或旋转结果。源图和 SVG 输入的重置在布局阶段完成，避免缓存图片的 load 事件或首次输入操作被延后的重置覆盖。

2026-09-15 验证：12 项文件读取/保存测试和 7 个现有 Story 交互场景通过；两类实际会话的下载文件与图片接口原文 SHA-256 相同，保存目标由模拟 File System Access 句柄验证。UI 面板在 1024×800 下下载按钮可聚焦、可见且无水平溢出，局部 WCAG 2 A/AA 检查无违规；组件场景覆盖 1280×800，构图面板在 1536×960 下按钮可见且无水平溢出。系统原生文件对话框未人工操作；测试浏览器截图接口超时，未留截图证据。类型检查、生产构建、Storybook 构建、i18n、YisiUI doctor 和领域基线检查通过；领域契约 173 项通过、1 项跳过。
