# 3D 空间壳层右栏

用户要求选中部位变色，并参照构图/UI 页面，把工具、基本信息、对象和参数迁入 AppShellFrame 的右侧栏。按已明确的两个标签页实现：信息与工具、对象与参数。摄像机与角色使用独立添加按钮；人物、关节、物体、摄像机统一在 AssetSkeletonTree 中选择。

已对比同步 AppShellFrame、AssetSkeletonTree、TabSwitch、BasicButton、CompositeButton，以及现有 Human2AiAppShell、Human2AiWorkspaceSidebar、CompositionCanvas 和 UI 页面工具门户。复用现有 AppShellFrame 右栏 slot 及开关，SpatialWorkspaceView 的受控 panelHost 将面板送入该 slot；不在场景里增加第二套侧栏。TabSwitch 负责两种面板视图，AssetSkeletonTree 负责人物与全部部位的两级结构、选择、键盘导航和展开；不采用拖动重新绑定骨骼。列表之外呈现参数表单。

选择、展开、面板标签和工具模式是本地视图状态；摄像机预览继续从页面注入，空间操作和持久化边界不变。画布中选择部位会同步树选择并展示对象标签；树中选择会高亮对应部位及相连骨段。选择角色高亮整个人物，选择普通物体高亮该物体。高亮使用编辑器的选中颜色，不写入文档或摄像机输出。

这些是 UI 呈现与交互调整，不改变领域操作、API、稳定 schema、关节约束或持久化流程，不触发领域能力提取。空间名称与新标签语义记录在 spatial 分片；基本信息和操作工具复用 shared 语义。共享资产仍属于同步 0.11.0 experimental release，本地组件保留 candidate / pending-user-review；本次布局方向由用户明确指定。

验收：Story 覆盖默认、空空间、加载、错误、禁用、四臂、长名称、英文、桌面最小尺寸；交互验证右栏归属、标签键盘选择、对象和镜头统一选择、关节独立固定、面板折叠和部位高亮。运行 i18n、YisiUI doctor、类型检查、Storybook 与生产构建，并在桌面浏览器检查尺寸和操作。

用户追加要求：人物下全部部位同级，不显示部位嵌套；人物、部位与摄像机保持一致的行高、图标尺寸和边距。仅改变视图节点的 parentKey，实际骨骼父子关系仍由 spatial 文档与求解器维护。空间树通过局部布局样式横向排布共享树的图标和标题，并把人物容器行对齐至摄像机内容行的尺寸；不修改共享资产。Story 明确检查所有部位只有一级缩进，没有部位嵌套，并比较人物、部位和摄像机的行高。
