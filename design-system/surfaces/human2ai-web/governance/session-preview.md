# 会话预览

用户已确认 UI 界面是目标编辑器：在同项目会话中选择构图/UI 的稳定状态 ID 或 3D 的摄像机 ID。禁止会话自身引用，允许交叉引用；主动编辑发起有限批次，每个会话每轮最多刷新一次，发起者不接收该轮反向更新。循环组固定输入版本，汇合分支先处理来源。预览仅从明确版本及其中保存的图片绘制，不递归请求嵌套来源。

会话预览、Agent 导出和界面“复制预览图”统一不绘制节点备注，保留文字节点的正文。UI 领域 SVG 渲染器负责这条规则，各入口直接复用；备注完整保存在原始草稿、历史版本及提示词中。构图与 3D 的既有引用渲染本身不绘制备注。仅备注改变时复用相同 PNG，不追加目标版本或更新目标画布；已有含备注的不可变预览在来源下一次保存或重新选择来源时替换。

沿用现有摄像机选择器的 Modal/Select 视觉结构，组合同步 BasicButton/CompositeButton、既有 UiSketchCanvas、CanvasImage 与 CanvasImageEditorFields。查询 shared dialog 能力无对应资产，SessionStylePicker 属于风格条目选择，不能承载会话输出；因此增加本地 candidate SessionPreviewPicker。所有 API、SSE、版本与来源选择状态归 web 应用适配器。没有改变已有视觉方向，没有修改 vendor 或宣称基线获批。

工具“会话预览”与“添加会话预览”及来源/失败提示在 session-preview 语义分片记录，中英文独立表达；取消、创建、重试和状态默认名称复用已有兼容语义。来源失效保留图片，并允许更换来源或另存普通图片。图片锁定上传来源但仍可裁剪、下载及编辑布局。历史草稿持有目标会话自己的不可变 PNG。

渲染边界：弹窗选择 -> 弹窗自身；源保存 -> SSE 通知、受影响预览生成、目标图片与既有保存信息；未变化查询 -> 零状态发布；预览替换 -> 相关 CanvasImage 解码并切换源，不创建客户端 3D 场景。目标页面只合并预览字段，保留本地打字/布局与未受影响条目；真实外部编辑保留现有冲突语义。同步派生图片不新增用户撤销步骤、不取消正在进行的指针手势；旧撤销快照保持独立。裁剪手势期间固定编辑器图片，松手提交最终裁剪后才呈现待更新来源。

服务端注册 local ui-sketch.session-preview，复用 shared draft-versioning、canvas-edit-history、图片校验及各领域渲染。旧构图摄像机引用的跨项目和浏览器轮询生命周期保持独立。正式同步发生在保存后，未保存的逐帧手势不属于本次范围。

浏览器验证及尺寸、模式和观察范围记录于忽略目录 `.human2ai-data/output/session-preview/`；原生 IME 需要人工输入，不从合成输入推断。Storybook 展示选择、英文、空状态与失败，CLI/API 回归覆盖源类型、状态、交叉引用、历史资产和写入边界。生产构建或类型检查不代替浏览器执行范围验证。

实测：1280×800 开发构建，50/500 个普通节点加一个引用，源保存后仅引用 CanvasNode 执行、SVG 仅 href 变化；另测两个引用和一个快照时，两个引用更新，快照及项目树零执行。未变化轮询零画布执行；生产构建验证更换状态保留几何、打开来源定位所选状态。保留 SessionPreviewRefresh Story 的局部执行与刷新中裁剪断言；本次通过浏览器手动驱动运行，现有 CI 只构建 Storybook，未声称 CI 自动执行浏览器回归。

## 预览文字纵向偏移修正（未运行验证）

对比 UI 画布 CanvasText 与共用 renderUiSketchSvg 后，确认画布使用节点顶部坐标和 `dominantBaseline="text-before-edge"`，而导出渲染器错误地使用 `y + fontSize` 和 `dominant-baseline="middle"`。同时导出优先使用 Inter/system-ui，画布则使用 YisiUI 的系统中英文字体顺序；导出按每行独立 text 绘制且未保留连续空格，与画布的 tspan/white-space:pre 结构不同。

修正现有 `ui-sketch.preview-export` 的 canonical 渲染器，直接使用节点相对画框的顶部坐标，沿用画布的 text-before-edge、400 字重、1.4em tspan 行距、空行占位与空白保留，字体顺序与当前同步的 YisiUI 字体 token 一致。会话预览服务、浏览器复制预览及 CLI 继续委托同一函数，不新增布局实现或修改业务协议，契约版本不变。未修改 CanvasText、指针/订阅路径、画布节点几何或 GPU 资源；只有下一次请求/保存产生的导出 SVG/PNG 改变。预览服务使用 SVG 内容 hash 缓存，因此新的 SVG 不会命中旧渲染结果。既有不可变 PNG 不追溯重写，需要来源再次保存并触发刷新，或重新创建引用。

静态查阅本机 sharp 随附的 librsvg 版本 2.62.91，以及相应上游 text.rs 中 compute_baseline_offset：该版本支持 text-before-edge，但浏览器与服务端的字体安装、回退及栅格化仍可能存在细微差异，未承诺跨环境像素完全一致。上游依据：https://github.com/GNOME/librsvg/blob/2.62.91/rsvg/src/text.rs 。用户要求自行测试，本次只进行了代码对照和上游实现查阅，没有运行测试、浏览器/图片像素比较、类型检查、治理检查或构建；此前的视觉计量不能代表此次修正已验证。

## 拖动预览与插入尺寸统一（待用户验证）
