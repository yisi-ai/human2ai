# UI 界面状态管理

UiSketchStateTabs 作为项目状态操作适配层，组合 YisiUI 0.18.0 experimental TabSwitch 和 Ant Design Input/Modal。共享组件负责单状态、尾部添加动作、hover 菜单和可取消的实时拖动排序；本地保留重命名、删除确认及焦点恢复，页面持有领域状态和保存。未手工修改 vendor 文件；组件保持 candidate，不声明新的已批准视觉基线。

- menu.trigger 使用 hover：悬停标签直接打开菜单；键盘聚焦操作入口后可打开菜单。菜单顺序：新建状态、重命名、删除状态；操作未选中项不切换选择。
- 使用共享 compact 密度及默认选中态；标签最长 240px，多项溢出复用共享箭头滚动。单状态通过 trailingAction 显示独立添加按钮。
- 新建复制所操作状态的几何及显示状态，插入其后并选中。重命名去除首尾空白，名称最长 100 字符。
- 删除必须确认，至少保留一个状态；删除当前状态后切换到相邻状态。
- 按住标签 350ms 后可拖动；原标签跟随指针、其他项实时让位。预览不修改正式顺序，内部松手确认一次；移出恢复原预览，外部松手取消，移回可继续。Esc、指针取消、丢失捕获、失焦、卸载或列表实际变化清理预览。
- 方向键、Home/End 切换；按用户要求移除键盘排序。共享 radiogroup 的选择项与菜单及尾部操作按钮并列。
- 状态名称、默认编号和顺序随现有草稿自动保存。复制菜单同步名称及顺序，状态过渡提示词覆盖相邻状态对。
- 旧草稿默认解析 start 和 stages。删除 start 后顶层节点仍是共享内容和内部几何基准，不再作为可编辑或导出的状态；其余完整快照不变。

迁移前验证记录（旧实现）：

- ui-sketch-state-tabs 单元测试覆盖旧草稿兼容、重命名、排序、复制快照、删除边界、非法元数据、旧调用方重建 end。
- 导出测试覆盖多状态顺序、用户名称及删除到单状态；API 测试覆盖名称、顺序和删除结果的保存/读取往返。
- Chromium 中 Interactions Story 通过；覆盖菜单首项、重命名、新建选中、键盘排序、350ms 长按排序及删除。长按使用合成 Pointer Events，Story 单独替代指针捕获以适配合成事件。
- Chromium axe 检查状态条无违规项；单状态菜单删除项 aria-disabled=true。
- 长名称在 1024、1280、1536px 桌面容器约束下检查省略和内部横向滚动；实际工作台已检查紧凑状态条。
- i18n、领域基线、YisiUI doctor、类型检查、相关测试、Storybook 和 Next 生产构建通过。

0.18.0 迁移验证：

- 本地菜单、选择和拖动实现已移除，保留 UiSketchStateTabs 作为领域操作与弹窗适配层。共享菜单采用 hover 模式，不新增 Story，原 Story id 保留。
- 实际 UI/构图路由使用隔离数据库、4 个状态和 20/200 个节点；函数入口计数验证拖动预览及外部取消均不执行画布或侧栏，两个子树 DOM 变更为零。内部松手仅保存一个新版本，选择和标签 DOM 身份保留；提交后的页面/画布更新仍由正式草稿变更触发。
- Chromium 交互 Story 覆盖菜单定位、非选中项操作、重命名、新建、实时让位、外部取消、内部确认和删除。单状态禁删/尾部添加、键盘菜单开关与焦点恢复、长名称和 480px 内部滚动通过。参考桌面窗口 1024/1280/1536px，浏览器实际 innerWidth 为 1025/1281/1537px。
- Web/Storybook 类型检查、i18n、相关状态测试、225 个领域契约测试（另有 1 个跳过）、YisiUI doctor/check、Next/Storybook 生产构建通过。浏览器检查为人工驱动，包含合成 Pointer Events，不代表原生 IME 或 CI 自动保护。
- Escape 仍会触发画布既有预览拖入层的 3 次 visibility 属性写入；该全局清理未因本次迁移扩大。详细证据与剩余限制在 ignored .human2ai-data/output/tabswitch-migration/verification.md。
