# 摄像机观察盒

沿用已使用的 AppShellFrame 右栏及信息与工具 / 空间对象 / 参数三个标签，不引入新页面方向。复用 source-sync 0.11.0 的 TabSwitch、AssetSkeletonTree、CompositeButton、BasicButton、ConfirmAction、LoadingState，字段沿用现有 Ant Design 控件；SpatialWorkspaceView / SpatialViewport 仍为本地 candidate。CompositionCanvas 与普通输出摄像机不能承担有体积裁切的六面取景，因此在现有空间对象体系内扩展观察盒，不新增独立存储或编辑器。

领域归属为 `spatial.scene-authoring@20`：复用 DraftVersionStore 的保存、冲突和撤销，复用现有场景蒙皮、三角形/线段裁切及三个参考图类型的渲染器。新增的局部责任仅为观察盒六个向内正交镜头及合图。普通摄像机和构图引用保留自己的输出职责。

语义先记录在 `locales/_meta/semantics/spatial.json`，再编写中文/英文。观察盒指有界的六面取景区域，区别于实体方块及最终构图摄像机；方向为盒子局部坐标，避免误解成人体左右。位置、旋转、取景类型、下载、复制和删除复用已有语义。Agent 的错误提示和多视图生图指引使用同一语义记录。

交互：独立按钮添加观察盒；统一对象树选择；边长、位置、旋转、单图分辨率可编辑；按真实蒙皮顶点框住全空间对象或全部手部。范围显式保存，不随姿势自动重新居中；画面随空间版本更新。选中盒框变色并出现三维移动/旋转工具。盒框只在编辑器显示。

默认预览 3×2 六方位合图，可选择各单面及普通图/结构线/深度图，再下载对应 PNG。六图相同缩放与裁切范围；顶面/底面有明确 up 方向；合图方向标签使用英文并附局部轴。普通图透明，结构线白底，深度黑底且全部视图共用盒子边长的归一化范围。六图供姿势理解使用，主镜头控制最终构图，提示词不要求还原分节线、身体分块或生成多宫格。

- `test/unit/spatial-camera-box.test.ts`：任意旋转下六面朝向、精确裁切、up 方向、盒外遮挡排除、单图与合图像素一致、透明与统一深度范围、形态保存及范围校验。
- `test/integration/spatial-camera-box.test.ts`：CLI 方法发现、操作、PNG 导出、错误参数、版本缓存、并发冲突、批次失败原子性、删除与撤销。
- `docs/evidence/spatial/camera-box-hands.png` 和 `camera-box-body.png`：用户原空间第 609 版的只读复制，采用同一版本、实际网格渲染，手部边长约 0.269 米，全身约 1.197 米；未改动原空间。
